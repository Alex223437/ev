# EV – řešené úlohy

Repozitář s řešeními úloh z předmětu EV. Každá úloha je v samostatné složce a spouští se nezávisle na ostatních.

| # | Úloha | Složka |
|---|-------|--------|
| 1 | Genetický algoritm (One-max, Leading ones) | [01-genetic-algorithm](01-genetic-algorithm/) |

## Prostředí

Python 3.10+. Virtuální prostředí je společné pro všechny úlohy:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Postup spuštění konkrétní úlohy je popsán v README její složky.
